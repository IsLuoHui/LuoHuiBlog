# 问题描述
在打开 VSCode 终端 或 Windows PowerShell 时，出现如下报错信息：
```bash
. : 无法加载文件 D:\User\Documents\WindowsPowerShell\profile.ps1，因为在此系统上禁止运行脚本。有关详细信息，请参阅 https:/go.microsoft.com/fwlink/?LinkID=135170 中的 about_Executio
n_Policies。
所在位置 行:1 字符: 3
+ . 'D:\User\Documents\WindowsPowerShell\profile.ps1'
+   ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
    + CategoryInfo          : SecurityError: (:) []，PSSecurityException
    + FullyQualifiedErrorId : UnauthorizedAccess
```
这个问题是因为 PowerShell 的默认执行策略设置限制了脚本的运行。你可以通过执行下面命令来查看当前的执行策略
```bash
Get-ExecutionPolicy -List
```


# 解决方法
1.临时生效（当前会话）
```bash
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
```
2.当前用户
```bash
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```
3.本机所有用户（需要管理员运行）
```bash
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope LocalMachine -Force
```
